# Blueprint-X

A Satisfactory mod (SML 3.12, game CL 513885+) to create a blueprint from **any size** of
area: place two corner markers and save everything between them as a blueprint. The server
collects the buildings itself, so it works on dedicated servers without hitting network
message limits.

**Status:** early development. Not released yet.

## Features

- **Blueprint-X Corner** marker (0.2.0): build menu > Special > Blueprint Designers; costs
  2 Iron Plates and is available from the start (no HUB milestone needed).
  Since 0.5.0 it is a 3 m orange post with a diamond beacon on a 1 m base, with floor arrows
  in all four directions (the box can grow from a corner either way).
- **Save window** (0.4.0): interact (`E`) with a Corner, pick the other corner (nearest first),
  set the extra height, name and description, and save. A box outline shows the area.
- **Building count** (0.6.0): the window shows how many buildings are inside the box before
  saving. The server counts them; only the two marker references and the height travel.
- **Adjust mode** (0.6.0): the Adjust button hides the window and gives control back while the
  box stays visible. `Page Up` / `Page Down` change the extra height; `Y` or using one of the two
  corners (`E`) brings the window back with the same values.
- The server collects and saves the buildings; tested in single player and on a Linux
  dedicated server (1674 buildings in one blueprint, synced to other players).
- **Save sound** (0.7.0): a short chime plays when a blueprint is saved. It is generated by
  `SourceArt/Audio/build_save_sound.py` (our own sound, no third-party clip).
- **Chat commands** (0.7.0), any player may use them:
  - `/bx save <name> [h=<metres>]` saves between the two Corners nearest to you
    (`/bxsave <name> [h=<metres>]` still works).
  - `/bx clear` removes every Blueprint-X Corner in the world (only Corners, never other
    buildings) and gives you their Iron Plates back, like dismantling them; if your inventory is
    full the rest goes into a crate next to you. Useful before uninstalling the mod.
  - `/bx help` lists the commands.

## Install (manual, until it is on ficsit.app)

The mod is a Game Feature plugin, so the folder goes one level deeper than older mods:

- Game (Steam): `<Satisfactory>/FactoryGame/Mods/GameFeatures/BlueprintX/BlueprintX.uplugin`
- Dedicated server: `<server>/FactoryGame/Mods/GameFeatures/BlueprintX/BlueprintX.uplugin`

The folder must be named exactly `BlueprintX`. Server and players need the same version.
Satisfactory Mod Manager does not know this mod yet and may remove it when it syncs a profile.

## Building

Set up the Satisfactory modding environment (https://docs.ficsit.app), place this folder in
`<SatisfactoryModLoader>/Mods/GameFeatures/BlueprintX`, build the editor and package with
Alpakit.

The marker model is made in Blender by a script, so it can be rebuilt at any time:
`blender -b --factory-startup --python SourceArt/Marker/build_corner_marker.py` writes
`SM_BXCornerPost.blend` and `SM_BXCornerPost.fbx` next to the script; the FBX is then
imported into `/BlueprintX/Buildings/Corner` (mesh `SM_BXCornerPost`, slots `M_BXCorner`
and `M_BXCornerDark`, `UCX_` boxes as collision).

The save sound and the mod icon are made by scripts too:
`python SourceArt/Audio/build_save_sound.py` writes `S_BXSave.wav` (imported as
`/BlueprintX/Audio/S_BXSave`), and
`blender -b --factory-startup --python SourceArt/Icon/render_mod_icon.py` renders
`BlueprintX_Icon_512.png` (the ficsit.app logo) from the marker model.
